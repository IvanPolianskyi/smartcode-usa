# Модуль 2 — Models, Union і будинок з вікнами

**Уроків:** 8 × 60′  
**Вхід:** Place з М1 («Мій перший двір»)  
**Артефакт модуля:** будинок `House` у дворі — Model з стінами, дахом, дверима і **вікнами через Negate/Union**  
**Скрипти:** немає

**Що має вміти учень після М2**
- Відрізняти Folder і Model; групувати обʼєкти
- Ставити PrimaryPart і розуміти навіщо
- Робити Union з кількох Parts
- Вирізати отвори NegatePart (вікно, арка, тунель)
- Чинити Union (Separate / переробка), не панікувати від помилок
- Користуватись Pivot / вирівнюванням без хаосу
- Додати Decal на стіну/табличку
- Здати будинок за рубрикою

**Безпека часу (важливо):** Union+Negate+цілий будинок ≠ 1 урок. Тут рознесено на 2.3–2.5 і фінал 2.8.

## Урок 2.1 — Model чи Folder?

**Ціль:** зрозуміти, коли «коробка для порядку», а коли «один предмет з частин».

### Артефакт
Лавка з М1 зібрана в `Model` з іменем `Bench`. Паркан лишається у `Folder` `Fence` (або створити, якщо не було).

### Підготовка викладача
- На екрані два приклади поруч: Folder зі сміттям vs Model лавки, яку можна виділити одним кліком і пересунути
- Гарячі клавіші: Ctrl+G (Group), Ctrl+U (Ungroup) — перевірити актуальні в версії Studio

| 17–30 | Разом: виділити частини Bench → Group → назва `Bench` → у `Yard` |

## Урок 2.4 — NegatePart: вирізаємо отвір

**Ціль:** зробити перше вікно (дірка в стіні) через Negate + Union.

### Артефакт
Одна стіна `Wall_WithWindow`: прямокутний отвір. Результат назвати `Wall_N` (або відповідна сторона).

### Алгоритм «на дошку» (кроки для дітей)
1. Зробити стіну-Part  
2. Зробити Part-отвір там, де вікно (тонкий «вирізач»)  
3. Negate на вирізачі  
4. Виділити стіну + negated → Union  
5. Перевірити отвір у Play (чи можна дивитись «крізь»)

### Таймінг 60′

| Хв | Дія |
|----|-----|
| 0–6 | Шоу кращих Union з ДЗ |
| 6–7 | Ціль: «Стіна з вікном без малювання наклейкою» |
| 7–17 | Демо повного алгоритму повільно; типові фейли (вирізач не перетинає стіну) |
| 17–30 | Разом: одне вікно на стіні-зразку |
| 30–48 | Самі: повторити на своїй `Wall_N` або `Wall_S`; Anchored результат |
| 48–53 | Челендж: вікно рівне (не «зламаний зуб») — взаємний огляд 1 хв |
| 53–58 | Тест |
| 58–60 | ДЗ |

### Часті фейли (розбір на демо)
- Вирізач не перетинає стіну → дірки немає  
- Вирізач занадто тонкий / не той орієнт  
- Забули Negate  
- Зробили Negate на стіні замість вирізача

## Нотатки для викладача М2

1. **Не давати готові вікна з Toolbox** — інакше Negate не закріпиться.  
2. Якщо в когось слабкий ПК: менше одночасних Union, частіше Backup, простіші отвори.  
3. Учні, що вже вміють Union: челендж арки над дверима або кругле вікно (циліндр-negate).  
4. Слідкувати за часом на 2.4–2.5 — тут найлегше «витекти» за годину. Краще одне якісне вікно, ніж три криві.  
5. Актуальні назви кнопок Solid Modeling можуть трохи відрізнятись у версіях Studio — звіряти перед семестром.
