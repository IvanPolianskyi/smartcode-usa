# Модуль 3 — Світ, ландшафт і атмосфера

**Уроків:** 6 × 60′  
**Вхід:** двір М1 + будинок М2  
**Артефакт модуля:** біом навколо двору (terrain / «підлога-світ»), освітлення, небо, звук зони; шлях гравця читається ще краще  
**Скрипти:** немає (свідомо)

**Що має вміти учень після М3**
- Базово користуватись Terrain Editor (малювати/прати ландшафт)
- Накладати матеріали ландшафту
- Налаштовувати Lighting / Atmosphere / Sky (без магії «наугад»)
- Додати Ambient/зональний звук
- Зробити міні-level design: орієнтири, контраст, безпечний край карти
- Здати «живий» острів/біом за рубрикою

**Нотатка про час:** повний «AAA terrain» за 6 уроків нереально. Ціль — **атмосферний міні-світ**, а не континент.

## Урок 3.1 — Terrain Editor: перша земля

**Ціль:** намалювати ділянку землі навколо двору й зрозуміти Add / Subtract / Grow / Erode (ті інструменти, що є в актуальній Studio).

### Артефакт
Пляма ландшафту навколо Foundation (або заміна «голої» Baseplate на природніший край). Двір і будинок **не закопані** випадково.

### Підготовка викладача
- Показати панель Terrain Editor
- Режим: краще почати з плоскої «подушки», не з гір одразу
- Як не знищити будинок: камера згори, малий brush, часті Undo/Save

### Таймінг 60′

| Хв | Дія |
|----|-----|
| 0–6 | Біом з ДЗ М2: хто який обрав (ліс/зима/вода…) |
| 6–7 | Ціль: «Земля під ногами, будинок цілий» |
| 7–17 | Демо: відкрити Terrain → Add плоскої зони → Subtract помилки → Undo |
| 17–30 | Разом: «подушка» землі під/навколо двору |
| 30–48 | Самі: розширити біом на 1–2 brush-зони; вирівняти стик з Path |
| 48–53 | Челендж: жоден Wall будинку не торкає «гору всередині кімнати» |
| 53–58 | Тест |
| 58–60 | ДЗ |

**Індивідуал:** маленька гірка **поза** двором (не на даху).

### ДЗ

## Урок 3.2 — Матеріали ландшафту і берег/декор біому

**Ціль:** покрити terrain матеріалами під біом; додати 1 «фішку» біому (вода / сніг / пісок / трава+каміння).

### Артефакт
Ландшафт з 2+ матеріалами (напр. Grass + Rock або Sand + Water). Короткий «край світу» позначений візуально (скеля/вода/огорожа з Parts — на вибір).

### Таймінг 60′

| Хв | Дія |
|----|-----|
| 0–6 | Огляд подушок terrain |
| 6–7 | Ціль: «Біом відчувається за 3 секунди погляду» |

| 30–48 | Самі: добити біом за своєю темою; міні-декор 3–5 Parts (камінь/кущ-імітація) |
| 48–53 | Челендж: скрін «від Spawn видно біомну фішку» |
| 53–58 | Тест |
| 58–60 | ДЗ |

**Група:** якщо вода лагає — альтернатива «синє озеро» з Part + Material/Transparency (чесно сказати: тимчасовий фейк).

## Урок 3.5 — Звук зони і «жива» локація

**Ціль:** додати Sound (ambient) так, щоб біом відчувався на слух; зрозуміти Volume / Looped / Playing.

### Артефакт
`AmbientSound` у Workspace (або в Part-зоні біля двору): looped, адекватна гучність. Опційно короткий one-shot на Sign (без скрипта — лише якщо вручну Playing; інакше лишити ambient).

### Підготовка викладача
- Безпечні free sound / Roblox library з дотриманням політики школи  
- Не глушити мікрофони групи під час уроку — Volume низький  
- Альтернатива: учні приглушують у себе, викладач демо на середній гучності

### Таймінг 60′

| Хв | Дія |
|----|-----|
| 0–6 | Галерея hero-скринів (швидко) |
| 6–7 | Ціль: «Закрив очі — і вгадав біом» |
| 7–17 | Демо: Insert Sound; SoundId; Looped; Volume; Play в Edit vs Play Mode нюанси |
| 17–30 | Разом: ambient під біом, Volume 0.2–0.5 |
| 30–48 | Самі: підібрати звук; перевірити що не бісить; назвати `Ambient_Biome` |
| 48–53 | Челендж: 10 сек тиша з закритими очима + вгадати чий біом (якщо звуки різні) |
| 53–58 | Тест |
| 58–60 | ДЗ |

**Без скриптів:** не вимагаємо Touched-зони. Якщо хтось сильний — можна згадати що «пізніше код увімкне звук у зоні», але не писати.
