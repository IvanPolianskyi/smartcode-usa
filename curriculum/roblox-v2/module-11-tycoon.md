## Урок 11.3 — Collector: гроші з дропу

**Ціль:** Touched collector знищує drop і додає монети власнику plot.

```lua
local function collect(drop, ownerPlayer)
	local value = drop:GetAttribute("Value") or 1
	ownerPlayer.leaderstats.Cash.Value += value
	drop:Destroy()
end
```

## Урок 11.7 — Збереження прогресу (сесія + DataStore lite)

**Ціль:** зберегти куплені кнопки + Rebirths + Cash (обережно з бюджетом DataStore). Для групи: спочатку **таблиця в памʼяті + BindToClose / PlayerRemoving**; DataStore — увімкнути в Studio API services якщо дозволяє школа.

### Мінімум здачі без продакшен-сейву
Гравець вийшов і зайшов у тій же сервер-сесії Studio — прогрес plot через Module-памʼять **або** пояснити обмеження і зберегти хоча б Rebirths у DataStore одним ключем.

**Канон SmartCode:** простий DataStore `Tycoon_UserId` з `{cash, rebirths, ownedButtons={}}`; pcall; не автосейв кожну секунду.

### Таймінг 60′
Страхи DataStore → шаблон pcall load/save → разом → самі ownedButtons restore → fail-safe → тест → ДЗ не спамити Save.
