# Гайд викладача — SmartCode Roblox v2 (92 уроки)

Короткий робочий стандарт для живих уроків (група ≤5 або 1:1).

## Перед уроком (5′)

1. Відкрити LMS-урок дня + `curriculum/roblox-v2/module-XX-…md` (таймінг / тест).  
2. Мати **Starter Place** (див. `starter-place/README.md`) або копію Place учня з минулого разу.  
3. Шаблони коду: `templates/` або блок «Шаблон коду» в LMS (кнопка **Копіювати**).  
4. Zoom + share Studio; Output увімкнено (View → Output).

## Ритм 60′ (група)

| Хв | Блок |
|----|------|
| 0–6 | Старт + 1 показ ДЗ |
| 6–7 | Ціль одним реченням (з LMS) |
| 7–17 | Демо викладача |
| 17–30 | Разом за чеклістом |
| 30–48 | Самі + обхід кожного |
| 48–53 | Челендж / взаємний огляд |
| 53–58 | Тест у LMS (≥70%) |
| 58–60 | ДЗ |

**1:1:** стиснути демо; більше часу на челендж / polish портфоліо.

## Правила групи

- Один стартовий Place на групу — без 5 саморобних KillBrick.  
- Імена латиницею / PascalCase.  
- М4: міняємо **числа/рядки/кольори**, не видаляємо рядки «бо не розумію».  
- Артефакт уроку = щось у Place, не лише «послухали».  
- Після чекпоінта — коротке «що добре / що далі» (30–60 сек на учня).

## Starter Place

Спека: `starter-place/STRUCTURE.md` + скрипти М4 у `starter-place/scripts/`.  
Учням: Download a Copy → `M{module}_Імʼя`.  
Підказка також в LMS на М1–М4.

## LMS і прогрес

- Після підрізки до **92** ревізія прогресу `v2-92`.  
- Lazy-migrate на відкритті курсу; bulk: `npm run migrate:roblox-progress` → з `--apply` на проді.  
- Перегенерація контенту: `npm run gen:roblox-v2`.  
- Шаблони: `npm run extract:roblox-templates`.

## Чекліст якості здачі модуля

- [ ] Place збережено в Roblox  
- [ ] Артефакт відповідає рубриці (якщо є)  
- [ ] Немає Part1/Part2 у ключовій зоні  
- [ ] Учень може сказати ціль 1 реченням  
- [ ] Тест ≥70% у LMS  

## Безпека / етика (М12–М13)

- Cartoon dummy / PvE, без реалістичної зброї.  
- Реальні GamePass / донати — лише за політикою школи; інакше ігровий «Premium» буст.  
- Publish може бути private + відео, якщо батьки проти публічності.
