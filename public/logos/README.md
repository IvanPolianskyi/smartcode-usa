# Логотипи курсів

Помістіть сюди PNG логотипи для курсів:

- `unity-logo.png` - Логотип Unity (для курсу Геймдев)
- `roblox-logo.png` - Логотип Roblox (для курсу Roblox)
- `webdev-logo.png` - Логотип веб-розробки (HTML/CSS/JS)

## Вимоги до зображень:
- Формат: PNG з прозорим фоном
- Розмір: мінімум 240x240px (рекомендовано 512x512px або більше)
- Фон: прозорий (PNG з альфа-каналом)
- Стиль: білий або світлий логотип для кращої видимості на темному фоні картки

## Примітки:
- Python логотип знаходиться в `/public/python-logo.png`
- Всі логотипи використовують Next.js Image компонент для оптимізації
- Розмір відображення: 180x180px
