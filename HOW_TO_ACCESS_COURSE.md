# Як відкрити сторінку курсу

## Крок 1: Запустіть сервер розробки

Відкрийте термінал у кореневій папці проекту та виконайте:

```bash
npm run dev
```

Або якщо використовуєте yarn:

```bash
yarn dev
```

Сервер запуститься на `http://localhost:3000`

## Крок 2: Відкрийте сторінку курсу в браузері

### Сторінка курсу (головна):
```
http://localhost:3000/courses/python-developer-zero-to-junior
```

### Сторінки уроків:

**Урок 1-2: Змінні та типи даних**
```
http://localhost:3000/courses/python-developer-zero-to-junior/lessons/lesson-1-2
```

**Урок 2-1: Умовні оператори**
```
http://localhost:3000/courses/python-developer-zero-to-junior/lessons/lesson-2-1
```

## Швидкий доступ

Після запуску сервера, просто скопіюйте та вставте один з URL вище у ваш браузер.

## Що ви побачите

### На сторінці курсу:
- ✅ Інформацію про курс
- ✅ Статистику (тривалість, кількість уроків)
- ✅ Навички, які ви отримаєте
- ✅ Повну програму курсу з модулями та уроками
- ✅ Кнопку "Купити курс" / "Продовжити навчання"

### На сторінці уроку:
- ✅ Теорію з кодом та прикладами
- ✅ Практичні завдання
- ✅ Інтерактивний тест
- ✅ Типові помилки та підказки

## Примітки

- Якщо сторінка не відкривається, перевірте, чи сервер запущено
- Переконайтеся, що ви використовуєте правильний `courseId`: `python-developer-zero-to-junior`
- Для уроків використовуйте правильні `lessonId`: `lesson-1-2` або `lesson-2-1`

## Додавання посилань на навігацію

Якщо хочете додати посилання на курс у головне меню, додайте в компонент Header:

```jsx
<Link href="/courses/python-developer-zero-to-junior">
  Курси
</Link>
```
