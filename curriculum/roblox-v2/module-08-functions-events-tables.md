## Урок 8.7 — Словник + діалог NPC

**Ціль:** таблиця ключ→значення; простий NPC click дає репліку з таблиці / масиву.

```lua
local replies = {
	hello = "Привіт! Ласкаво просимо у двір.",
	bye = "Бувай, заходь ще!",
}

local function talk(key)
	local text = replies[key]
	if text then
		print(text)
	else
		print("...")
	end
end

talk("hello")
```

Проєкт уроку: Part `NPC` + ClickDetector викликає `talk` по черзі з масиву реплік (індекс-прапорець).
