# Звіт аудиту доступності (a11y Audit Report)

Дата: 2026-08-27  
Стандарт: WCAG 2.1 Level AA  
Платформа: SmartCode LMS & Web Platform

---

## 1. Резюме аудиту

Проведено комплексний аудит доступності ключових сторінок та компонентів системи:
- Головна сторінка (`/en`, `/uk`)
- Каталог курсів (`/en/courses`)
- Сторінка курсу (`/en/courses/[courseId]`)
- Сторінка уроку (`/en/courses/[courseId]/lessons/[lessonId]`) — вкладки Теорія, Практика, Квіз, бічна панель навігації
- Авторизація та реєстрація (`/en/login`, `/en/register`)
- Модальні вікна та інтерактивні елементи

---

## 2. Перевірка клавіатурної навігації (Keyboard Accessibility)

| Критерій | Статус до аудиту | Статус після виправлення | Деталі |
| :--- | :--- | :--- | :--- |
| **Видимий фокус (`:focus-visible`)** | Відсутній глобальний фокус-ринг | **Виправлено** | Додано висококонтрастний фокус-ринг `outline: 2px solid var(--brand-accent)` з `outline-offset: 2px` у `src/app/globals.css` для всіх інтерактивних елементів (`button`, `a`, `input`, `select`, `textarea`, `[role="tab"]`, `[role="radio"]`). |
| **Пастки фокусу (Focus Traps)** | Відсутні у звичайному потоці | **Пройдено** | Клавіатура вільно переміщується між сайдбаром, табами, редактором коду та футером. |
| **Редактор коду (`LessonPractice`)** | `Tab` перехоплювався для відступів | **Покращено** | Підтримується `Ctrl+Enter` для запуску коду без миші, `Shift+Tab` для деіндентації. |
| **Квіз (`LessonQuiz`)** | Опції кнопок доступні з клавіатури | **Пройдено** | Вибір відповіді здійснюється за допомогою `Space` / `Enter` на кнопках-опціях, сабміт за допомогою `Enter` на кнопці Submit. |
| **Закриття модалок / віджетів по `Escape`** | Працює у віджетах підтримки | **Пройдено** | Віджети обробляють подію клавіші `Escape`. |

## 3. Семантика та ARIA-атрибути

| Елемент | Реалізація ARIA | Призначення |
| :--- | :--- | :--- |
| **Таби уроку (`LessonNav`)** | `role="tablist"`, `role="tab"`, `aria-selected`, `aria-controls` | Чітка навігація між секціями уроку для скрінрідерів. |
| **Контентні панелі (`LessonPage`)** | `role="tabpanel"`, `aria-labelledby`, `hidden` | Правильне зв'язування панелей вмісту з відповідними вкладками. |
| **Квіз (`LessonQuiz`)** | `role="radiogroup"`, `aria-label`, `role="radio"`, `aria-checked` | Семантичне групування питань та варіантів відповідей. |
| **Статуси / вердикти (`LessonQuiz`, `LessonPractice`)** | `role="status"`, `aria-live="polite"` | Автоматичне озвучування результатів перевірки коду та квізу. |
| **Декоративні іконки (`Lucide`)** | `aria-hidden="true"` | Ізоляція декоративних іконок від скрінрідерів. |
| **Хлібні крихти (`Breadcrumb`)** | `<nav aria-label="Breadcrumb">`, `aria-current="page"` | Семантична розмітка орієнтації в структурі курсу. |
| **Кнопки навігації сайдбара** | `aria-label`, `title` | Додано описові текстові мітки для кнопок згортання/розгортання. |

## 5. Додаткові вдосконалення

1. Додано utility-клас `.sr-only` у `src/app/globals.css` для надання прихованого контексту користувачам програм читання екрана.
2. Додано підтримку `prefers-reduced-motion` у `src/app/globals.css` для вимкнення анімацій для користувачів із вестибулярними порушеннями.
3. Додано підтримку семантичного атрибута `aria-current="page"` для поточного уроку в навігаційному дереві.
