# Модуль 4 — Іскри: готовий код і перше «вау»

**Уроків:** 10 × 60′  
**Вхід:** живий світ після М1–М3  
**Артефакт модуля:** «іскровий» parkour/дворик з **кількома працюючими механіками** (готовими скриптами) + коротка презентація  
**Скрипти:** так, але формат **шаблон → вставити → змінити параметри → пояснити рядок**. Повний самостійний код з нуля — з М5.

**Правило М4 (написати дітям на дошку):**
1. Не видаляємо чужі рядки «бо не розумію»  
2. Змінюємо спочатку **числа, рядки, кольори**  
3. Ломаємо навмисно → дивимось помилку → повертаємо  
4. Кожен скрипт має імʼя і місце (ServerScriptService / всередині Part — за шаблоном уроку)

**Що має вміти учень після М4**
- Вставити Script / LocalScript за інструкцією
- Знайти Output і прочитати просту помилку
- Змінити параметри в готовому коді
- Зібрати 5+ механік у свій двір
- Пояснити своїми словами: «цей скрипт робить X коли Y»

## Урок 4.2 — Kill brick (готовий Touched)

**Ціль:** вставити готовий скрипт смерті на Part; змінити повідомлення / зрозуміти Touched.

### Артефакт
Part `KillBrick` на доріжці (збоку або пастка). Гравець торкається → Reset/смерть (Humanoid.Health = 0).

### Шаблон (всередині KillBrick → Script)
```lua
local brick = script.Parent

brick.Touched:Connect(function(hit)
	local character = hit.Parent
	local humanoid = character:FindFirstChild("Humanoid")
	if humanoid then
		humanoid.Health = 0
	end
end)
```

**Параметри для зміни учнем:** колір Part; можна додати `print("Ай!")` перед смертю.

## Урок 4.3 — Checkpoint (збереження точки)

**Ціль:** готовий чекпоінт змінює Spawn / точку відродження (шаблон викладача під рівень групи).

### Артефакт
Part `Checkpoint_1` на середині Path: після дотику смерть на KillBrick повертає сюди (або оновлює SpawnLocation — за обраним шаблоном школи).

### Шаблон A (простий для молодших) — оновити SpawnLocation позицію
Викладач дає **один затверджений шаблон** у репо курсу / чат. Нижче — ідея логіки для педагога (адаптувати під робочий код):

```lua
-- ШАБЛОН: Checkpoint оновлює SpawnLocation
local checkpoint = script.Parent
local spawn = workspace:FindFirstChild("SpawnLocation")

checkpoint.Touched:Connect(function(hit)
	local character = hit.Parent
	local player = game.Players:GetPlayerFromCharacter(character)
	if player and spawn then
		spawn.CFrame = checkpoint.CFrame + Vector3.new(0, 3, 0)
		print(player.Name .. " досяг чекпоінта!")
	end
end)
```

> Якщо шаблон нестабільний у вашій версії — тримати **внутрішній «викладацький» .rbxl шаблон** і роздавати код 1:1 без імпровізацій.

## Урок 4.4 — Монета і leaderstats

**Ціль:** зібрати монету; побачити рахунок у списку гравців (leaderstats).

### Артефакт
`Coin` Part + скрипт: +1 до `Coins`, монета зникає (`:Destroy()`). У `ServerScriptService` — шаблон створення leaderstats.

### Шаблон leaderstats (SSS)
```lua
game.Players.PlayerAdded:Connect(function(player)
	local leaderstats = Instance.new("Folder")
	leaderstats.Name = "leaderstats"
	leaderstats.Parent = player

	local coins = Instance.new("IntValue")
	coins.Name = "Coins"
	coins.Value = 0
	coins.Parent = leaderstats
end)
```

### Шаблон монети (у Part Coin)
```lua
local coin = script.Parent
local DEBOUNCE = false

coin.Touched:Connect(function(hit)
	local character = hit.Parent
	local player = game.Players:GetPlayerFromCharacter(character)
	if player and not DEBOUNCE then
		DEBOUNCE = true
		local coins = player:FindFirstChild("leaderstats")
			and player.leaderstats:FindFirstChild("Coins")
		if coins then
			coins.Value = coins.Value + 1
		end
		coin:Destroy()
	end
end)
```

**Параметри для учнів:** `+ 1` → `+ 5`; колір монети; розмір.

## Урок 4.5 — Двері на ClickDetector

**Ціль:** клікнути на двері → відкрити/зсунути Part (готовий шаблон).

### Артефакт
`GateDoor` з ClickDetector: після кліка двері зʼїжджають / роблять CanCollide false + Transparency (обрати 1 простий шаблон і не міняти на уроці).

### Шаблон (зсув по осі)
```lua
local door = script.Parent
local click = door:FindFirstChild("ClickDetector")
local open = false

if not click then
	click = Instance.new("ClickDetector")
	click.Parent = door
end

click.MouseClick:Connect(function(player)
	if open then return end
	open = true
	door.Position = door.Position + Vector3.new(0, 0, 4)
	print(player.Name .. " відкрив двері!")
end)
```

**Параметри:** `4` → інша відстань; напрямок осі; колір дверей.

## Урок 4.7 — Платформа, що зникає (готовий ефект)

**Ціль:** стати на Part → через N секунд Part зникає/падає (шаблон на `task.wait` + Destroy або Transparency/CanCollide).

### Артефакт
`FadePlatform` на Path: встигни пройти.

### Шаблон (простий, без TweenService — стабільніше для М4)
```lua
local platform = script.Parent
local busy = false

platform.Touched:Connect(function(hit)
	local character = hit.Parent
	if not character:FindFirstChild("Humanoid") then return end
	if busy then return end
	busy = true
	task.wait(1.5)
	platform.CanCollide = false
	platform.Transparency = 1
	task.wait(3)
	platform.CanCollide = true
	platform.Transparency = 0
	busy = false
end)
```

**Параметри:** `1.5` час до зникнення; `3` час відновлення.
