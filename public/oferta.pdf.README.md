# Інструкція для PDF файлу публічної оферти

## Розміщення PDF файлу

1. Створіть PDF версію публічної оферти з того ж контенту, що і на сторінці `/oferta`
2. Назвіть файл `oferta.pdf`
3. Розмістіть файл в директорії `/public/`
4. Файл буде доступний за адресою: `https://smartcode-academy.com/oferta.pdf`

## Як створити PDF

Ви можете:
- Експортувати сторінку `/oferta` в PDF через браузер (Ctrl+P → Зберегти як PDF)
- Використати онлайн-сервіси для конвертації HTML в PDF
- Створити PDF вручну в текстовому редакторі (Word, Google Docs) з того ж контенту

## Важливо

Перед створенням PDF не забудьте заповнити в документі:
- Повне фірмове найменування
- ІПН
- Юридичну адресу
- Фактичну адресу
- Контактний телефон

Ці поля позначені як `[ВКАЖІТЬ ...]` на сторінці оферти.
