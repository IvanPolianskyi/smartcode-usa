## Урок 10.2 — Збір: Touched / Click + Power

**Ціль:** функція `grantReward(player)` додає `Power` до `Coins` (або окремий ресурс); респавн монети через wait/цикл.

### Артефакт
≥5 collectables; debounce; використання Power.

```lua
local function grantReward(player)
	local ls = player:FindFirstChild("leaderstats")
	if not ls then return end
	local coins, power = ls.Coins, ls.Power
	coins.Value += power.Value
end
```

### Таймінг 60′
Демо → разом одна монета → самі система на Folder → баланс Power старту=1 → тест → ДЗ.
