## Урок 9.2 — Пастки: функція applyDamage / kill

**Ціль:** Module або local functions для kill bricks; кілька пасток без копіпасту скрипта в кожен Part (один Script + CollectionService **або** простіший варіант: тег-папка + цикл по children).

### Рекомендований педагогічний варіант (без CollectionService спочатку)
Folder `Hazards`; Script у SSS:
```lua
local function killCharacter(character)
	local humanoid = character:FindFirstChild("Humanoid")
	if humanoid then
		humanoid.Health = 0
	end
end

local function hookHazard(part)
	part.Touched:Connect(function(hit)
		local character = hit.Parent
		if character:FindFirstChild("Humanoid") then
			killCharacter(character)
		end
	end)
end

for _, part in ipairs(workspace.Obby.Hazards:GetChildren()) do
	if part:IsA("BasePart") then
		hookHazard(part)
	end
end
```

## Урок 9.4 — Рухомі платформи (цикл / Heartbeat lite)

**Ціль:** платформа їздить між точками A–B.

### Педагогічний варіант (зрозумілий)
```lua
local platform = script.Parent
local start = platform.Position
local offset = Vector3.new(10, 0, 0)
local t = 0

while true do
	t += 0.03
	local alpha = (math.sin(t) + 1) / 2
	platform.Position = start:Lerp(start + offset, alpha)
	task.wait()
end
```
Або простіший «туди-назад» з прапорцем напрямку без sin — на розсуд викладача.

**Anchored = true**; гравець стоїть — обговорити що ідеальна фізика платформ складніша (не обіцяти AAA).

local function onFinish(player)
	if finished[player.UserId] then return end
	finished[player.UserId] = true

	-- показати ScreenGui Win (RemoteEvent lite АБО сервер дає підказку через перевірку на клієнті пізніше)
