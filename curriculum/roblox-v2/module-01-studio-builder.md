# Модуль 1 — Робочий стіл будівельника

**Уроків:** 8 × 60′  
**Артефакт модуля:** локація «Мій перший двір» (доріжка, паркан, лавочка, табличка, впорядкований Explorer)  
**Скрипти:** немає (свідомо). Лише Studio, Parts, Explorer, Properties, інструменти.

**Що має вміти учень після М1**
- Відкрити Studio, зберегти Place, орієнтуватися камерою
- Читати й прибирати хаос в Explorer (імена, Folder)
- Створювати Parts: розмір, колір, Material, Anchored, CanCollide
- Працювати Move / Scale / Rotate + Snap to Grid
- Розуміти базову різницю Workspace / ServerStorage / ReplicatedStorage
- Зібрати маленьку локацію за чеклістом

## Урок 1.1 — Ласкаво просимо до Studio

**Ціль одним реченням:** відкрити Studio, зробити перший Part і зберегти свій Place.

### Результат уроку (артефакт)
Place з іменем `M1_Dvir_Імʼя` + один Part `Foundation` (підлога двору) на сітці.

### Підготовка викладача
- Перевірити, що в усіх є Roblox-акаунт (13+ або з батьківським)
- Шаблон: порожній Baseplate АБО «Blank»
- На екрані показати: Home → New → Baseplate; кнопку Save to Roblox

### Таймінг 60′ (група ≤5)

| Хв | Дія |
|----|-----|
| 0–6 | Привітання. Хто вже грав у Roblox? Хто відкривав Studio? |
| 6–7 | Ціль: «Сьогодні у кожного зʼявиться свій Place і перша підлога» |
| 7–17 | Демо: запуск Studio → Baseplate → камера WASD/ПКМ → Insert Part → Rename → Save to Roblox |
| 17–30 | Разом: кожен створює Place, Part `Foundation`, розмір приблизно 20×1×20, Anchored = true |
| 30–48 | Самі: перейменувати Baseplate або видалити зайве; зробити Foundation сірим Material Concrete; перевірити Save |
| 48–53 | Челендж: хто швидше і акуратніше збереже + надішле скрін Explorer у чат групи |
| 53–58 | Тест |
| 58–60 | ДЗ |

**Індивідуал:** челендж — додати другий Part `WelcomeSign` (поки просто блок-табличка).

### Робимо разом (чекліст на дошку)
1. New → Baseplate  
2. Part → перейменувати на `Foundation`  
3. Anchored = ✓  
4. Save to Roblox → назва `M1_Dvir_Імʼя`

### Часті помилки
- Не зберегли Place (після перезапуску все зникло)
- Part провалився / не Anchored
- Пишуть українською в іменах обʼєктів з пробілами без системи — домовитись: `PascalCase` або `snake` латиницею

## Урок 1.2 — Камера й перша доріжка

**Ціль:** вільно крутити камеру й зібрати рівнішу доріжку з кількох Part на сітці.

### Артефакт
Доріжка `Path` з 8–12 блоків від краю `Foundation` до «воріт» (позначити двома стовпами).

### Таймінг 60′

| Хв | Дія |
|----|-----|
| 0–6 | 1–2 скріни ДЗ; швидко відкрити Place |
| 6–7 | Ціль: «Пройдемо по доріжці у Play Mode» |
| 7–17 | Демо: ПКМ + WASD / F для фокусу; Snap; Duplicate (Ctrl+D); вирівнювання |
| 17–30 | Разом: 4 блоки доріжки підряд, однакова висота Y |
| 30–48 | Самі: доростити до 8–12; два стовпи `GateL` / `GateR`; Material Brick/Concrete |
| 48–53 | Челендж: пройти доріжку в Play Mode без зістрибування (Anchored?) |
| 53–58 | Тест |
| 58–60 | ДЗ |

**Індивідуал:** доріжка з поворотом на 90°.

### Три шари практики
1. Разом — 4 блоки  
2. Самі — ще 4–8 + ворота  
3. Челендж — Play Mode тест «чи рівні»

## Урок 1.3 — Explorer: порядок у світі

### Артефакт

```
Workspace
  Yard (Folder)
    Foundation
    Path (Folder) → блоки доріжки
```

|----|-----|

## Урок 1.4 — Part і Properties: паспорт обʼєкта

### Артефакт

| Хв | Дія |
|----|-----|

## Урок 1.5 — Move, Scale, Rotate + Snap

**Ціль:** точно ставити обʼєкти інструментами трансформації, без «кривого хаосу».

### Артефакт
Паркан `Fence` з 6–10 секцій по периметру частини двору + вирівняна лавка біля доріжки.

### Таймінг 60′

| Хв | Дія |
|----|-----|
| 0–6 | Швидкий огляд стільців з ДЗ |
| 6–7 | Ціль: «Паркан по прямій — як у справжніх будівельників» |
| 7–17 | Демо: Move/Scale/Rotate; гарячі клавіші; Snap step; Rotate 90° |
| 17–30 | Разом: 3 секції паркану в лінію |
| 30–48 | Самі: доробити паркан; підігнати Bench до Path; виправити «дірки» |
| 48–53 | Челендж на час: 4 рівні секції без наїзду одна на одну |
| 53–58 | Тест |
| 58–60 | ДЗ |

**Група:** у кінці голосування «чий паркан найрівніший» (1 хв).

### ДЗ

## Урок 1.7 — Де живуть обʼєкти: Workspace і «коробки» Storage

**Ціль:** зрозуміти різницю Workspace / ServerStorage / ReplicatedStorage на пальцях (без скриптів).

### Артефакт
У `ServerStorage` лежить запасна копія моделі лавки `Bench_Backup` (Group поки можна як Model або просто скопійовані Parts у Folder). У Workspace — тільки те, що має бути видно в грі.

### Таймінг 60′

| Хв | Дія |
|----|-----|
| 0–6 | Показ SignBoard |
| 6–7 | Ціль: «Не все має валятися посеред двору» |
| 7–17 | Демо трьох місць + аналогія: сцена / склад за кулісами / валіза для клієнта й сервера (простими словами) |
| 17–30 | Разом: скопіювати Bench у ServerStorage як Backup; оригінал лишити в Yard |
| 30–48 | Самі: створити Folder `Props` у ServerStorage з 2 запасними Part-декорами; перевірити що в Play їх НЕ видно, поки не перенесеш у Workspace |
| 48–53 | Експеримент: перенести Prop у Workspace → видно; назад → сховали |
| 53–58 | Тест |
| 58–60 | ДЗ |

**Важливо для викладача:** не грузити RemoteEvent. Лише сенс «де лежить».

### Аналогії для дітей
- **Workspace** — сцена спектаклю (видно всім)  
- **ServerStorage** — склад за лаштунками (гравець не бачить)  
- **ReplicatedStorage** — спільна валіза ресурсів (детальніше зʼявиться зі скриптами)
